01 · Problem & Value

Useful knowledge should be easy for an AI assistant to access—without moving it to the cloud.

Scattered information

Notes and FAQs can be stored locally but still be difficult to search naturally.

Manual retrieval

Users should not need to open data files and scan them manually for every answer.

Local control

The runtime keeps project data local and does not depend on a cloud database or external API.

Our answer: Give an AI host a small set of explicit MCP tools instead of giving it unrestricted access to the data layer.

04 · Safety by Design

Every boundary is intentionally narrow.

01

Input validation

Model input is checked with Zod before handlers use it.

02

Filesystem protection

Data access is restricted to the project’s allowed local data area.

03

Bounded output

Search and list results use limits and controlled output sizes.

04

Safe writing

add_note, update_note, and delete_note validate controlled local note mutations before saving changes.

05

Safe errors

User-facing errors stay short while technical details use stderr where needed.

06

Secret hygiene

The repository includes ignore/example environment practices and no real secret logging.

05 · Offline Runtime

The MCP server itself keeps working when the network is unavailable.

What stays local

  • Tool handlers
  • Zod validation
  • Notes and FAQ data
  • Search and retrieval logic
  • Validated note writes, updates, and deletes

How we verified it

With Wi-Fi disabled, MCP Inspector can start the local stdio server, list its tools, and invoke tools against the local JSON files.

The offline claim applies to our MCP server runtime. Claude itself still requires connectivity to the Claude service.

06 · Claude Desktop Integration

The project runs as a real local MCP server inside Claude Desktop.

Project MCP

notes-faq-search exposes the project’s seven tools and two resources to Claude over stdio.

Claude→notes-faq-search→Local data

Live code-edit demonstration

For Demo Day, a separate restricted filesystem MCP integration can be given access only to the project directory. Claude can then edit a real project file, and Git shows the exact local diff.

This filesystem integration is a development/demo companion. It is not one of the seven tools implemented by the Notes & FAQ Search server.
